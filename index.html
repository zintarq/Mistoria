FAQ

Ответы на частые вопросы. Не нашёл своё — напиши нам в Discord.

Как начать играть?
  1. Запусти Minecraft Java Edition 26.2 с лицензионного аккаунта.
  2. Добавь сервер: Многопользовательская игра → Добавить сервер → введи IP сервера (пока неизвестен, объявим перед открытием).
  3. Получи доступ: напиши администрации в Discord, и тебя добавят в вайтлист.
  4. Построй свой дом. Спавна нет, его игроки строят сами уже во время сезона.
Какая версия Minecraft нужна?

Minecraft Java Edition 26.2.

Нужна ли лицензия?

Да, сервер работает только для лицензионных копий Minecraft Java Edition.

Сколько стоит играть?

Ничего. Mistoria полностью бесплатна: это проект для друзей, без донатов и платных преимуществ.

Есть ли вайтлист?

Да, сервер закрытый и создан для друзей. Доступ выдаётся по приглашению, напиши администрации в Discord.

Нужны ли моды?

Сервер работает на самописных модах, их список есть в разделе «Инфо». Подробную инструкцию по установке опубликуем перед открытием.

Что такое «Ледяные истории»?

Это текущий сезон сервера с общим сюжетом, ивентами и вечной зимой. По итогам сезона мир сбрасывается, а лучшие истории попадают в летопись.

Как связаться с администрацией?

Через Discord или командой /report в игре. Отвечаем обычно в течение дня.
